# 威胁模型、安全与隐私控制

版本：0.1.0 · 日期：2026-10-27 · 状态：待评审 · 责任角色：安全负责人。依据：PRD §17、§19、AC-009/013。

## 资产与信任边界

最高保护资产是源世界、当前目标、保护备份和恢复证据。次级资产为元数据、环境档案、用户路径及未来凭证。信任边界包括 WebView→Rust、下载源→本地解包、原始存档→解析器、第三方归档→恢复器、用户路径→文件操作、应用→Git/游戏、最小报告→可选 AI。

本机当前用户权限已完全被恶意程序接管不在可保证边界内；仍须避免把普通损坏文件或恶意压缩包升级为命令执行和任意路径写入。仅需要用户级权限。

## 风险与控制映射

| 威胁 ID | 具体场景 | 强制控制 | 验证 |
|---|---|---|---|
| TH-01 | TAR 路径穿越、链接逃逸、重复/PAX 路径 | 有效路径规范化、无跟随打开、精确集合、安全类型白名单 | TC-SEC-01 |
| TH-02 | 解压炸弹、超大/深层 JSON、文件数耗尽 | 流式限额、CPU/时间预算、解析错误隔离 | TC-SEC-02 |
| TH-03 | 参数注入、Git hooks/filters 或环境执行 | 参数数组、受控 Git 环境、禁用外部扩展、固定命令 | TC-SEC-03 |
| TH-04 | 预览后替换目标目录或重新启动游戏 | 后端范围锁、身份/指纹复检、PLAN_STALE | TC-RES-03 |
| TH-05 | 恢复中断造成目标缺失 | 已验证保护、同卷 staging、持久 journal、逐阶段回滚 | TC-RES-02 |
| TH-06 | UI 被不可信内容诱导调用危险命令 | 最小 IPC 能力、前后端校验、内容作为文本呈现、导航限制 | TC-SEC-04 |
| TH-07 | 下载资产/更新包被篡改 | 来源白名单策略、HTTPS、可信摘要/签名验证、失败隔离 | TC-REL-02 |
| TH-08 | 日志、档案、AI 泄露隐私 | 默认本地、导出预览、路径令牌化、秘密独立存储、授权外发 | TC-SEC-05 |
| TH-09 | 同名角色误合并、跨世界恢复 | 稳定世界 ID、边界证据、默认世界级恢复 | TC-WORLD-01 |
| TH-10 | 自动清理唯一有效备份 | scope 保底、锁定保护、执行前重新计算 | TC-BACKUP-03 |

工程实现要将每条控制映射到代码位置和测试证据。当前为威胁模型基线，不是已完成安全审计。

## 桌面权限设计

UI 仅访问本地受信任资源；远程内容在受限外部浏览器打开。CSP、Tauri capability 和命令权限按实际框架版本核验后锁定，拒绝通配开放所有文件系统和 shell。用户选目录授予路径引用，不授予任意字符串路径写入；符号链接、挂载点变化和路径别名在每次高风险操作前复检。

存档、diff、资源元数据中 HTML/Markdown/控制字符均为不可信内容，默认文本转义；不能当作提示指令、代码或可执行链接。归档清单不能替代用户恢复确认。

## 隐私与生命周期

| 数据 | 默认位置/策略 | 导出/外发 |
|---|---|---|
| 原始存档、角色/地图内容 | 用户本地源及备份 | 诊断默认排除；AI 不接收 |
| 绝对路径、用户名 | 必要时本地元数据 | 导出替换为稳定 scope token |
| 任务/错误日志 | 本地轮转 | 用户预览后导出，无自动上传 |
| 游玩时长 | 可关闭、最小记录 | 不默认上传 |
| AI 最小报告 | 功能默认关闭 | 授权后仅发送预览类别 |
| 凭证 | 平台安全存储（若引入） | 不进入 SQLite、档案或日志 |

日志建议保留 30 天、总量 100 MiB，待性能和支持需求确认；保护备份不受日志保留规则影响。遥测默认关闭，未来添加须单独列出字段、目的、保留期与撤销流程。

## 依赖与事件响应

每次发行产生依赖清单、许可证清单、SBOM 和漏洞扫描结果；严重性结合可达性评估，存在可利用的任意写入/执行或数据丢失风险不得发行。发现泄露或恢复缺陷：停止受影响发行 → 保留脱敏证据 → 定位版本与影响操作 → 提供保护/恢复说明 → 修复与回归 → 发布公告。不要为了排查自动上传用户世界。
