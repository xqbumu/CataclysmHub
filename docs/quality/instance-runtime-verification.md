## 实现及约束

方案固定将 HOME、TMPDIR/TMP/TEMP、XDG_CONFIG_HOME/XDG_CACHE_HOME/XDG_DATA_HOME/XDG_STATE_HOME 指向实例 `.hub-runtime` 下六个角色目录，保留现有 DYLD 包内框架覆盖。只改变当前子进程的环境，不修改 Hub 或系统环境。旧 v1、通用方案与普通启动保持原行为。

预览只读，确认时复核方案、目录身份及框架布局；启动意图和审计提交后才准备目录。通过目录能力及 nofollow 逐层打开，新建 Unix 运行环境目录 0700；已有普通目录复用且不修改其权限。占位文件或符号链接拒绝，不覆盖、不删除、不自动清理运行环境。

## 未验收项

HOME/XDG 变量不是 OS 沙箱，其他环境仍继承，系统 API 或绝对配置路径可能写到范围外。安装内缓存、代码签名、程序完整布局、子进程行为、真实新世界保存与重载、Hub 多版本并发仍需单独取证。实例整根备份包含 .hub-runtime，因此可能包含临时文件；既有特殊文件与链接拒绝规则不变。
