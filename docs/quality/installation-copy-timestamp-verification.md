# 安装副本修改时间验证

日期：2026-10-28。背景：Hub v2 真实 I 实验中，副本 JSON 字节一致但修改时间变化，出现温缓存旧数据错误。本切片只扩展复制格式，不自动删除缓存或抑制游戏错误，也不修改游戏版本、资源或绑定状态。

## 契约与自动回归

新建副本清单/回执为 v2，普通文件修改时间按有符号 Unix 纳秒字符串固定在清单中；使用目标文件句柄 set_times 后立即核对精度，所有失败均发生在完成标记移除之前。旧 v1 继续读取且不改写，数据库仍为 10。

新增五个集成回归覆盖：精确保留并拒绝只改目标时间、旧 v1 忽略时间且原始清单不改写、Unix epoch 前的文件时间、预览后只改来源时间不能完成，以及旧格式持久任务重启后独立核验登记。跨文件系统精度无法满足时应显式失败，不承诺未实测平台/文件系统均能保留纳秒。

两轴复核未发现确定的新格式、摘要、文件句柄设置或失败发布缺陷。完整检查与真实样本对照结果追加于下方。
