## 原生桌面演练

使用独立合成 schema 7 工作区与自建 shell 参数接收器，仅在测试临时目录写入。原生应用升级至 schema 8 并生成 v7 副本；未接触真实玩家存档，也未执行下载的第三方游戏。

1. 游戏库默认不勾选试运行方案，实例预览按钮禁用；勾选后可预览。
2. 预览显示程序、工作目录、实例根、固定参数、目标 save、摘要及四项边界提示。
3. 取消后直接查询 SQLite：会话 0、审计 0，实例根仍空。
4. 再次预览并确认：显示实例运行中与真实 PID。自建接收器只在 instance/save/world.dat 写 `native synthetic save`、instance/config/options.json 写 `native synthetic config`；原工作区 save 仍为空。
5. 程序退出码 0，记录 `exited_unverified`，保留实例 ID、方案 ID、数据根；有启动意图和进程结果两条审计。UI 显示“进程已退出，存档未验证”。
6. 正常关闭并重启原生应用，实例会话仍存在，方案选择重新默认为关闭；未自动启动或反填绑定已验证。
