## 发现并保留的失败

1. 直接本体没有包内框架环境时由 dyld 拒绝启动。已增加 macOS 明确试运行方案的布局检查及当前进程环境预览/传递。
2. I-1 首次检查退出 1，未因“有输出”记成功。补配置子目录后 H/I 两检查均退出 0；进一步以同一温缓存和新目录做独立对照：config 不预建退出 1、预建退出 0。确认启动流程现在在启动意图审计提交后准备 save/config；预览不创建目录。
3. 图形测试启动器最初把 --basepath 与 --datadir 同时覆盖，导致 gfx 指向错误并出现 tile_config.json 错误；改为仅显式 basepath 后正常。产品试运行保留 Resources cwd，不添加 datadir 覆盖，也不允许额外参数覆盖。
4. 在获得正常图形窗口之前发生过自动化连接失败及窗口重建，未将这些尝试计为游玩通过；最终通过原生窗口操作和加载结果判定。

## 实际执行

- 第一轮 --check-mods dda：H 退出 0，I-1 退出 1，两个检查进程重叠约 6.89 秒。补 config 后第二轮均退出 0，重叠约 6.63 秒。检查会创建/删除测试世界，不能称为只读，也不能用重叠时长代替游玩。
- H 界面新建默认场景进入世界 Beulaville，保存角色 Carli 'VIP' Morse；I-1 新建进入 Braham，保存 Christopher Pierre。两进程同时存在且分别显示世界场景，不只是菜单。
- H 保存退出至自身世界/角色列表，重新加载到原世界；I-1 保持活动。之后反向保存退出 I-1 并重载至原世界，H 保持活动。
- 最后正常保存退出 H 并关闭进程，I-1 PID 仍保留，且可响应主菜单操作；再保存关闭 I-1。没有留下测试游戏进程。
