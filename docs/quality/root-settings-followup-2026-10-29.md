## 修复

1. 首次配置时先从原生选择器选根目录，随后系统默认路径才返回：旧 effect 会覆盖用户草稿。现用本地编辑标记保护首次草稿；已配置工作区的默认值异步变化也不参与表单重新填充。
2. 已有工作区切换根目录会将备份也切到新位置，导致有历史引用的用户必须重新选择原目录。现默认保留登记的备份路径；只有显式点击备份项“跟随根目录”或另选目录才修改，后端历史引用保护保留。
3. 目录草稿变化清除旧确认，复制和打开等操作执行期间禁用重复操作；路径操作行减少不必要的分隔与留白。

README 已同步根目录切换与备份覆盖规则。本轮不搬迁数据、不修改后端准入或数据库，不增加迁移机制。

验证：前端格式、类型、119 项组件测试和生产构建通过；最终 macOS 普通 Debug 打包通过。新增回归覆盖迟到系统默认值以及切换根目录时原备份位置保留。本轮未重复执行 Rust/Python，也未将上轮原生 UI 验收当作本次新交互的人工验证。
