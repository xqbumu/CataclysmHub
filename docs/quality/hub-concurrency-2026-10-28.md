# Hub H/I 并发候选实际验证

日期：2026-10-28。被测提交：`5eadf70`，macOS arm64 debug 构建，显式启用 `candidate-concurrency`。结论：Hub 并发启动、独立角色加载、交替手动保存和正常退出已有实际证据；当前验收契约 C 仅部分完成，USR-001 未完成。

## 环境与证据

沿用 [原生入口验证](macos-native-entry-verification.md) 的 H/I 修改版 QA 封装及 [固定候选指纹](../design/candidate-concurrency.md)。不是未经修改的官方发行包认证。两份安装已存在温缓存，本轮不清理缓存。

通过真实 Hub 界面导入两个本体、登记两个空实例。确认没有活动会话后，复制既有测试世界到专用实例 `h` / `i`，不使用硬链接。此步骤是测试夹具准备，不代表 Hub 已实现存档迁移。测试根为 `/private/tmp/hub-concurrent-qa-rqzpsmun`；原始测试数据 `hub-window-qa-haihv653/hub-h`、`hub-i` 作为保护对照。

所有启动都经过 Hub 预览和确认，没有外部启动器、数据库状态修改或临时取消互斥。证据来自原生窗口观察、只读 SQLite 会话记录、进程查询和范围快照。[证据索引](evidence/hub-concurrency-2026-10-28.json)包含本地原始证据路径和 SHA-256；大型快照、游戏包、完整存档不提交。截图只存在本次工具观察记录中，不宣称存在仓库截图附件。

## 实际结果

| 操作 | 观察结果 |
|---|---|
| H 启动并进入世界，随后由 Hub 启动 I | H PID 4057、I PID 13015 同时运行；分别加载 Hardtner / Lashonda Kohler 与 Kaibito / Galen Nielsen |
| 两个世界交替操作和手动保存 | H 菜单 Quicksave（b），I 菜单 Quicksave（e），均显示保存消息；两版快捷键不同，不能复用同一按键脚本 |
| H 正常退出，I 继续 | H 退出码 0，状态 exited_unverified；I PID 13015 保持运行，推进至 08:00:08 后再次快速保存 |
| I 运行期间重启 H | Hub 创建新 H PID 21107，角色列表仍为 Lashonda Kohler，进入 B-19 避难所；仅 H 实例出现 6 项快照变化，I 实例 0 项 |
| H 运行期间重启 I | Hub 创建新 I PID 29503，加载 Galen Nielsen，C-41 避难所；退出前与重载后均观察到 Spring 61 08:00:10；仅 I 实例出现 9 项快照变化，H 实例 0 项 |
| 结束测试 | 四次会话均退出码 0，状态均为 exited_unverified；进程查询未发现上述 PID 存活 |

H 首次快速保存画面为 08:00:06，退出后只读解析 `.sav` 的 `turn=5212806`、`game_start=5212800`。H 新进程加载后的观察为 08:00:13，随后操作 I 时 H 后续观察为 08:00:16；I 也曾从 08:00:08 变为 08:00:10。用户随后确认测试期间也在人工操作游戏，因此这些观察混合了人工与自动操作，撤回“额外回合推进可能是输入异常”的疑点，不据此安排焦点或按键投递修复。这不是受控输入实验，仍不能把 H 精确时间恢复或两窗口输入互不干扰标为通过，也不能据此认定存档串写。后续由用户人工游玩，验收另设明确的保存状态与观察时点。

最终六范围快照：H 实例 71 项变化，I 实例 41 项；两份完整安装和两份原始测试实例均 0 项。变化计数包含文件身份变化，不等于内容变化数量。两实例允许变化的总差异结果只能说明未观察到保护对照变化；两次单侧重载对照进一步限定了对应阶段的观察结果。未采集 OS 全量写入归因，不能证明根外零写入或持久沙箱隔离。

## 本轮修复与未完成项

实际 Hub 的资源面板错误显示“没有活动资源占用”：组件只以全局声明选取所有者，遗漏仅有目录声明的运行候选。现改为按 owner_kind / owner_id 汇总全部声明，保留全局声明优先展示原因；两个候选显示两个会话及各自完整目录。资源检查对话框同步说明只读检查不预留资源、不授予并发资格。

修复新增目录声明回归；`npm run check` 通过（57 项前端测试、格式、类型检查、生产前端构建）。真实游戏实验使用修复前的已打包 `5eadf70`，本轮修复未在该运行包中热替换；后端准入未修改。

仍需完成：受控的精确 H 状态重载、物品与地图改动恢复、近同时保存、冷缓存/自动保存、并发故障矩阵、原始发行包可重复入口准备。开发并行推进不相关实例的备份范围检查；不向正在游玩的游戏自动发送按键。继续保留默认构建的全局保护、实验候选限制和 binding_verified=false；不新增泛用租约或自动信任机制。
