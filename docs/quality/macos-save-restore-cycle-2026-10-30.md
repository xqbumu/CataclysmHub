## 实测发现及最小修复

1. 只有配置的实例也能正常备份，但界面没有明确指出 save 为空。实例预览现在按完整清单提示 save/ 下没有普通文件，仍允许配置备份，不推断游戏格式或进度。
2. 完成恢复后，原“登记新实例”仅接受空目录，无法继续游玩恢复内容。现在同一入口可接收 Hub 成功恢复的 data/，其他普通非空目录仍拒绝。登记复用原 mutation 门、资源占用、目录重叠、程序摘要、200 实例限制与幂等处理，并在 blocking worker 内重新核验受登记归档和数据。只允许与来源实例相同的 installation ID 和 SHA-256，拒绝未完成标记、数据篡改、错误安装和普通非空目录；不复制、不覆盖原实例，不提升 binding_status。

恢复资格直接查询持久记录，不受首页历史条数上限影响。登记时须保留备份、成功恢复记录及可核对的来源实例；这是受限恢复继续游玩路径，不是任意旧存档导入或跨版本迁移。
