# 自动启动适配界面验收

日期：2026-10-29，基线 118cc58 上的本轮前端修改；macOS Apple Silicon Debug 应用。

## 实现

已识别且没有已保存启动偏好的实例，点击“启动”后自动识别并请求新的后端启动计划，直接进入“启动游戏”确认页。没有点击确认就不启动、不保存偏好。确认页显示实例、存档、简短保护说明，完整警告与环境参数放在“启动技术详情”；实验候选仍单独明确提示。

“启动设置”中不再提供把 profile ID 当作“游戏版本”的普通下拉框。已识别且匹配的方案显示自动适配；已保存自定义或实验设置保留，只有显式选择“使用自动适配”才切换草稿。未知安装保留明确提示与折叠的手动排障/实验选项。已保存普通方案仍经过新后端计划再一键启动，不更换底层进程引擎、目录参数或并发准入。

## 原生实测

复用隔离 QA 元数据，登记新的 H 托管实例“自动适配确认验收”，没有预先写入启动偏好。点击“启动”，等待当前程序摘要识别和计划检查后，直接显示启动确认，没有手选版本或高级方案；取消后返回实例列表。随后打开该实例“启动设置”，显示识别 H-RELEASE 和“启动适配：自动”，高级区保持折叠。

只读核对：操作前后 session 数均为 6；新实例没有启动偏好记录，实例目录仍为空。游戏没有启动，既有 H/I 世界未加载。新实例登记会创建空实例目录及元数据；不将其描述为全部操作零写入。

前端 121 项测试、格式、类型与生产构建通过，macOS 普通 Debug 打包成功。新增回归覆盖首次自动生成计划但不启动、取消不保存、保存自定义方案不被自动覆盖；旧有未知安装、候选检查与已保存方案失败不启动回归继续通过。本轮未改 Rust，不重复执行 Rust/Python 测试。
