# CI/CD、打包、发布与升级策略

版本：0.1.0 · 日期：2026-10-27 · 状态：待评审 · 责任角色：发布负责人。依据：PRD §21、§20.2。

## 流水线设计

| 阶段 | 触发 | 检查/产物 | 门禁 |
|---|---|---|---|
| PR 快速检查 | 每个 PR | 文档/契约、格式、lint、类型、单元测试 | 全部通过 |
| 集成检查 | 核心变更及合入 | Git/SQLite/归档/恢复、恶意输入和离线测试 | 数据保护用例不可跳过 |
| 多平台验证 | 发布候选及平台变更 | 三平台安装启动、核心 E2E、故障注入 | 声明支持的平台全部通过 |
| 供应链检查 | 发布候选 | 锁文件、漏洞、许可证、SBOM | 可利用高风险问题阻断 |
| 构建签名 | 已审阅发布 commit | 平台包、校验摘要、签名/证明 | 秘密仅受保护环境可读 |
| 发布验收 | 同一批签名产物 | 安装、启动、备份恢复、升级回退 | 签名产物本身通过冒烟 |
| 发布归档 | 放行后 | release notes、矩阵、测试和恢复说明 | 证据完整、已知限制清晰 |

CI token 最小权限；第三方 action 与依赖固定不可变版本/提交，缓存不包含秘密。来自不可信分支的代码不能获得签名密钥或写发布权限。定时故障注入可扩展覆盖，但不替代发布候选门禁。

## 平台矩阵

| 平台 | 目标架构 | 当前状态 | 正式发行前必须填写 |
|---|---|---|---|
| macOS | Apple Silicon | 首要验证目标，未验证 | 最低 OS、包格式、签名/公证、APFS 行为、权限 |
| Windows | x64 | 目标平台，未验证 | 最低 OS、安装包、代码签名、NTFS 锁/长路径 |
| Linux | x64 | 目标平台，未验证 | 支持发行版/运行库、包格式、文件系统、权限 |
| macOS Intel / Linux ARM64 | 待定 | 不声明支持 | 构建和测试能力获确认后单独加入 |

包格式由 M0 选型验证决定，不预先声称某一打包形式已具备。游戏版本支持与应用 OS 支持分别记录，不能从能安装推导能安全恢复。

## 发布档案

每次发行保存应用版本、源码 commit、构建环境、依赖锁、SBOM、平台资产和 SHA-256、签名状态、全量 AC 结果、故障注入报告、兼容矩阵、数据库/清单/档案版本、迁移说明、已知问题和回退步骤。PRD §1.1 可靠性指标须附样本定义。

## 升级与回退

下载更新包与安装游戏资产采用独立信任链，应用更新签名需核验，具体更新通道在 M0/发布设计评审确定。默认不在恢复/备份临界区自动退出升级。

升级前停止新的写任务、等待或安全取消当前任务、备份一致性元数据、记录旧应用/DB schema。升级不得更改原始游戏存档。失败先恢复旧应用及匹配的元数据快照；新 schema 不兼容旧应用时明确阻止直接降级。回退不删除升级后生成的独立备份，使用兼容恢复工具读取。

备份 v1 reader 对支持的旧格式必须有回归样本；遇到未知主版本只读拒绝恢复，不猜测字段。新写格式发布前先确保兼容读取与迁移工具方案；不能先淘汰旧 reader 再补恢复能力。

## 放行清单

- 全部发布阻断用例通过，S0/S1 为零；scope 与 release notes 一致。
- 用最终签名产物完成独立备份及恢复演练，源/目标证据可核验。
- 许可证、资源再分发和商标声明由维护者核验；不复用对标项目素材。
- 下载资产、签名、校验和发布说明互相对应；回退与支持入口已准备。
- 放行责任人、日期和例外记录归档，当前文档不代表放行。
