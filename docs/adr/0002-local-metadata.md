# SQLite 元数据与独立恢复日志

PRD 规定 SQLite 且数据库故障不应破坏存档。建议 SQLite 保存可查询元数据，备份自带清单，恢复另写可持久化 journal；重启通过文件事实对账，而非假设 SQL 与文件操作原子完成。

## Considered Options

仅靠数据库任务状态更简单，但 DB 损坏或落盘顺序差异会丢失恢复判断依据；完整事件溯源增加模型和维护成本。独立 journal 只覆盖高风险文件副作用，保持恢复证据最小化。

## Consequences

需实现孤立归档重新索引、journal 校验和受限模式；元数据不是恢复载荷的唯一入口。日志自身损坏时保留候选数据并要求人工处理。
