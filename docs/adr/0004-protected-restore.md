# 保护后使用同卷目录切换恢复

PRD AC-008/009 要求恢复前保护且中断不破坏当前数据。建议先完整保护当前目标，在同卷隔离目录验证新数据，然后以 journal 跟踪旧目标移出与新目标移入，验证后保留回滚证据。

## Considered Options

逐文件覆盖节省空间，但中断后新旧混杂且难以证明一致；平台特定文件系统快照效率好，但不能作为三平台统一前提。目录切换需要额外空间，也不能把两次 rename 当作原子事务，因此必须逐阶段对账。

## Consequences

范围锁覆盖游戏启动和写任务；网络文件系统等未验证路径只开放空目录恢复。M3 的强杀和回滚失败用例全部通过后才允许覆盖模式。
