# 世界独立仓库与受控载荷

PRD GIT-001/004 要求世界隔离和完整数据。建议每个世界在管理器工作区拥有独立 Git 仓库，提交冻结清单和按内容摘要命名的原始载荷，以隔离用户存档中的 Git 特殊路径、过滤器和空目录语义。源目录不作为 worktree。

## Considered Options

直接在世界目录初始化 Git 简单且 diff 直观，但引入控制目录和配置副作用；多世界共享仓库省管理开销但恢复边界更难审计；编码镜像路径可保留路径差异却需处理更多平台路径冲突。内容载荷方案将恢复范围显式化，代价是 UI 必须按清单生成 diff，Git 增量压缩效果需实测。

## Consequences

Git 历史恢复依赖清单物化器，独立灾备仍由完整归档提供。M0 未通过容量和原字节往返验证前不采纳；方案变更须同步更新检查点格式和测试。
