# 游戏适配、资源管理与环境迁移

版本：0.1.0 · 日期：2026-10-27 · 状态：待评审 · 责任角色：游戏与资源模块负责人。需求：GAME、WORLD、MOD、MIG 全组、AC-012。

## 游戏适配器

GameAdapter 按游戏分支和明确版本范围注册，输出能力而非单一 supported 布尔值。能力分别为安装识别、启动、世界边界、角色识别、配置读写、结构化解析；每项附 adapter_version、fixture_set、验证平台和 evidence_ref。未知版本可作为不透明文件备份，不能套用已知版本规则写配置。

| 接口 | 输入 | 输出与限制 |
|---|---|---|
| detect_installation | 只读候选目录 | 可执行文件候选、版本来源、置信状态；不得执行未知程序只为探测 |
| discover_worlds | save_root、版本证据 | 世界/角色候选、共享与未知集合；边界有版本 |
| build_launch_plan | 安装、档案、参数、目标世界 | executable、args[]、cwd、save_root、环境变量白名单 |
| inspect_configuration | 只读配置 | 已识别字段、未知字段、支持的资源角色 |
| plan_configuration_change | 原配置、期望组合 | 补丁计划与冲突；未知字段原样保留 |

世界 ID 独立于路径；同名世界、同名角色不得合并。用户移动路径后先比较指纹和上下文再关联，不能凭别名恢复身份。格式不明时仅索引候选并提供范围确认。

## 安装和启动

导入保留原安装；安装状态为 discovered / ready / unavailable / invalid。版本 unknown 仍可由用户明确选择启动，但预览必须显示未知和参数，不宣称已验证。启动前核对可执行文件、平台/架构、工作目录、环境档案、存档路径和冲突锁。

管理器保存进程 PID、启动时间、可执行文件身份及父子关系。子进程接管、启动器退出但游戏仍运行、应用重启等情况必须纳入实测；无法确定运行状态时阻止自动稳定标记。停止管理器不默认终止游戏。

更新安装采用并存目录，验证新资产后切换选择；旧版本仍被世界/档案引用时保留。升级前展示受影响世界，按用户选择创建检查点/备份；选择的保护失败则暂停更新，不能静默忽略。外部安装只登记与提示，不直接覆写。

## 下载与供应来源

远端发现列为后续能力。每个资产记录原始 URL、最终来源、抓取时间、期望大小、上游摘要及其来源、实际计算摘要、验证结果、许可证信息。只有自算哈希而无可信上游摘要时显示“已记录摘要，来源真实性未验证”。

下载到临时目录，限制重定向目的地和协议、文件大小、超时；断点续传须验证资产身份未变化。校验失败隔离，不安装。下载缓存与安装目录分离；安装后生成文件清单，资源解包复用备份引擎的路径安全规则。

## 资源与配置事务

资源类型为 mod、soundpack、tileset、font；tileset 的角色由游戏配置决定，不能推定所有版本支持 Overmap 图块。每包记录 name/version/source/digest/license/compatibility；缺失值为 unknown。

兼容枚举为 tested / upstream_declared / inferred / unverified / incompatible，并附明确游戏版本、平台、资源组合和证据日期。MSXotto+ 初始状态为 unverified。

启用组合先解析可得依赖图，检测缺失依赖、循环、重复 ID 和已知冲突。未知依赖不当成无依赖。实验世界使用独立档案及配置目标，禁止复用可写主世界配置。启用/禁用/升级操作先预览配置 diff、受影响世界和保护建议；覆盖自定义文件必须逐项提示。

配置写入使用同卷临时文件、旧内容保护、校验和受控替换。提交后验证资源引用与配置一致；失败恢复旧配置，保留已下载资源供诊断。卸载先扫描所有世界/档案引用，要求迁移引用或显式确认，不自动删除依赖包。

## 环境档案与迁移

档案导出使用 [JSON 契约](../contracts/file-formats.md)，引用便携游戏/资源身份，不复制游戏本体、不带个人绝对路径和凭证。配置内容仅在用户明确选择时导出，默认是相对引用与摘要。不能取得资源时仍可导入档案并显示 missing 状态。

迁移：读源 → 预检目标平台路径和版本资源差异 → 预览 → 复制至新隔离目录 → 按源清单验证 → 发布目标与新绑定。源文件始终保留。跨平台大小写/规范化冲突、非法文件名、权限/链接差异、路径长度全部列为阻断项或明确风险，禁止自动改名后冒充原始恢复。

迁移可完整复制不透明存档，但“文件相同”不等于“游戏可加载”。首次启动前显示版本/资源差异；游戏加载验证在测试世界进行，避免原存档被游戏自动升级。失败清理只清理该任务拥有的目标临时目录。


## 2026-10-28 实施约束补充

版本管理不仅是显示名称。安装身份/证据、存档实际关联、版本/分支/资源差异、升级前保护点和隔离首次加载需要逐项实现；当前 version/branch 和备份 game/profile/world_contexts 仍未知，不反填猜测。该基础必须早于危险清理、受控升级切换或覆盖恢复开放，详见 [版本与存档影响范围](version-save-impact-scope.md)。只读保留预览可先交付，但不授权删除，也不承诺任何跨版本兼容。
