# 交互规格与可访问性验收

版本：0.1.0 · 日期：2026-10-27 · 状态：待评审 · 责任角色：产品设计、前端、QA。依据：PRD §15、APP-001～005。

## 页面与信息层级

| 页面 | 必需信息与主要动作 | 空态/错误态 |
|---|---|---|
| 首次设置 | 安装、存档、备份、资源目录；权限和重叠检查 | 路径无效时解释原因，保留已填字段 |
| 概览 | 运行状态、最近检查点、最后验证备份、监控健康、失败任务 | 尚无世界时引导导入，不显示绿色健康 |
| 游戏库 | 版本/分支/平台、来源、引用世界、启动预览 | unknown 与 unavailable 分别呈现 |
| 世界 | 别名、角色关联置信、标签、主/实验分类、最后版本 | 未知边界提示确认，不伪造角色 |
| 历史 | 提交、父记录、实际文件差异、事实/推断/未知、证据 | Git 缺失显示安装帮助及完整备份入口 |
| 备份 | scope、容量、consistency、verification、卷状态、校验/恢复/删除 | 卷脱机仍显示记录；校验过期提示复验 |
| 资源与档案 | 资源类型、来源、许可、依赖、组合、兼容证据 | 缺失资源和未知依赖不使用“兼容”状态 |
| 设置与诊断 | 路径、策略、摘要语言、联网/隐私、日志导出 | 非法策略保留原配置并提示 |

统计页面为可选能力，关闭后不展示虚假零时长；运行监测与统计收集权限分开。

## 安全恢复向导

步骤为：选择来源 → 选择目标 → 校验与差异 → 保护说明 → 明确确认 → 进度 → 结果。确认页显示目标路径、世界、关联角色、覆盖/新增/移除数量、版本资源差异、当前状态保护位置与空间需求。危险按钮文案为“保护当前世界并恢复”，默认焦点放在取消/返回。

目标变化导致计划失效时回到预览，保留来源选择。用户取消确认不得开始覆盖。任务进入切换关键区时取消按钮显示“完成安全切换后停止”；窗口关闭不等于任务取消。成功结果区分别列出字节校验、采集一致性和游戏兼容状态。

## 状态文案

| 后端状态 | 建议用户文案 |
|---|---|
| verification=verified, consistency=quiescent_checked | 文件校验通过；已完成稳定性检查 |
| verification=verified, consistency=best_effort | 文件校验通过；采集时可能存在不一致 |
| monitor failed | 监控已停止，自动检查点不可用 |
| protection failed | 当前数据保护失败，恢复尚未覆盖目标 |
| recovery_required | 上次操作中断，需要恢复检查；保留的数据副本可查看 |
| compatibility=unverified | 该版本与资源组合尚未验证 |

通知可关闭展示但不抹去任务结果和阻断告警；后台失败在概览持续可见至已处理。普通成功使用非打断通知，高风险确认使用模态交互。

## 可访问性与本地化

所有动作有键盘路径、可见焦点和语义名称；对话框限制焦点并在关闭后回到触发点。进度有文本描述和辅助技术可读状态；错误关联具体输入。颜色配合图标与文字，不单用红绿表达。

测试浅/深色、200% 缩放、高 DPI、长中文路径、英文文案膨胀、屏幕阅读器和纯键盘恢复流程。默认中文，所有用户文案走本地化键；日志 code 保持稳定英文枚举。绝对路径在用户主动选择/高风险确认中完整可见，在普通日志和诊断中脱敏。

验收以任务完成率及无误操作为主，截图只是辅助。文件 diff 或备份列表达到大规模时使用分页/虚拟化，不能让哈希/归档阻塞界面。
