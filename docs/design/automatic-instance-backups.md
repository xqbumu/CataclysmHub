# 用户配置的实例自动备份与保留规则

日期：2026-10-30；沿用完整归档、新目录恢复及实例来源约束。

## 配置和使用

从游玩环境的“存档与备份”进入，展开“此实例的自动备份与保留策略”。每个实例独立保存，默认关闭：

- 用户可明确开启“正常退出后自动备份”，配置最小备份间隔0—10080分钟；0表示每次符合条件的退出。开启或修改启用策略需单独勾选完整范围/磁盘占用/尽力快照确认。
- 当前只支持已识别的 macOS H/I 受控原生方案。未知程序不能开启；退出时仍重新核对程序及本次启动方案，不依赖名称猜测。自定义方案和并发候选不参与自动触发。
- 最近份数0—1000、每日UTC窗口0—366天、每周UTC窗口0—104周作为该实例保留预览的默认规则保存。命名、保留锁、恢复引用、未知或不可用记录及最近校验保底等现有规则优先。
- 保留预览只统计当前实例，不混入工作区存档或其他实例；候选不会被删除。规则不是已交付的自动清理功能。
- 重新读取按钮更新最近自动结果及草稿；保存使用配置revision检查，过期草稿不能覆盖更新。关闭策略不取消已经开始的备份任务；可在原任务界面取消。

本轮触发方式是“Hub观察到正常退出后”，不是定时后台服务、每次游戏内保存监听或启动前备份。只有Hub持续运行并实际wait到对应进程退出才能触发，重启不补做。

## 触发与保护

进程结果持久化成功、状态为exited_unverified且退出码0后，释放原mutation门，再请求自动备份门。没有升级binding_status或宣称存档稳定。

自动路径重新读取持久策略，按会话ID记录一次尝试；关闭策略或未知/异常退出不生成自动归档。持有mutation门检查全局资源、实例来源/数据根、当前程序摘要及方案，复用原实例身份和路径隔离校验。其他活动/未知会话或文件任务存在时跳过，不绕过门禁。

间隔只参考同实例、同数据根且记录为verified的最近副本；它用于控制频次，不保证该介质此刻有效。当前源save没有普通文件时跳过，避免把只有配置的归档宣传为进度保护。

符合条件后复用现有预览、容量检查、冻结复制、源复核、归档回读验证及发布逻辑，不新增备份格式或弱化预算。归档仍为best_effort，外部写入与游戏语义不能由进程退出证明。备份任务关联原实例ID、源根和本次会话请求键；用户可在历史、任务和自动结果中核对。

不满足条件记录skipped及错误码；已经开始的任务使用原任务真实状态显示成功、失败或中断。相同会话不会重复请求，重启将遗留checking标为interrupted，不重放。进程结果或自动状态记录失败保留原保护状态/任务记录，不把日志失败解释为文件未变更。

## 数据和配置重置

schema16→17按已有机制先创建并校验元数据副本，再事务创建automatic_backup_policy和automatic_backup_run。策略按实例存JSON、revision、更新时间；尝试按会话唯一记录策略revision、任务、状态和错误。失败回滚、旧版本拒绝新schema的边界保持。

保存策略同时更新全局偏好revision，使旧重置预览失效。配置重置前JSON备份同时保存自动策略原始记录；备份成功后事务清空启动偏好和自动策略，默认关闭。归档、尝试历史、实例及游戏文件保留，不中止已开始的任务。

## 自动回归与实际验收
