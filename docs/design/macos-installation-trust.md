# macOS 安装隔离属性的显式处理

日期：2026-10-30。依据 [启动器源码调研](../research/macos-launcher-reuse-review-2026-10-30.md)。这是安装级安全属性变更，不是正常 Gatekeeper 授权，也不授予游戏兼容或存档绑定认证。

## 用户流程

只在游玩环境首页 macOS 异常结束卡片的“macOS 启动与授权检查”中提供“检查此安装的隔离属性”。读取范围是只读动作；没有隔离属性、程序样本未知或范围不可完整核对时返回说明，不开放通用解锁。

预览展示准确的安装包路径、待处理属性数量、程序摘要及属性记录位置。明确只有程序摘要匹配，仍需人工核对完整下载来源；不能把它当恶意软件拦截的通用修复。用户单独勾选风险确认并点击“确认仅移除此安装的隔离属性”后才执行。取消不创建属性备份、不修改属性。失败不自动重试，本次确认按钮禁用，继续前需重新检查。

成功只刷新工作区状态，用户仍从原游玩环境按钮启动。没有自动启动、更改游戏参数、改写脚本/plist、重新签名、关闭全局 Gatekeeper 或记住可自动授权所有版本的偏好。

## 后端约束

- 新接口 prepare_installation_quarantine(installation_id)、apply_installation_quarantine(plan_id, confirmed)。前端不能传入任意待写路径。
- 仅 macOS 实际实现，其他系统明确返回 PLATFORM_UNSUPPORTED。适用样本复用既有识别器；不新增任意文件或全部变体的隐式信任。
- 准备与确认都复用 mutation 门、活动/未知会话及文件任务门禁；同时检查安装与实例、工作区存档/备份/资源及 Hub 元数据目录分离。
- 预览最长五分钟、最多四份。保持原安装目录句柄，确认重新核对全包清单内容、路径、inode/device、链接数、模式与全部待处理属性，防止过期范围或替换目录沿用确认。仍是受控操作检查，不是阻止外部进程修改文件的 OS 沙箱。
- 复用安装复制的有界、无跟随清单：最多 20000 项、64 GiB 文件字节及已有清单元数据预算。外部/悬空链接和共享普通文件拒绝，内部链接仅核对，不跟随修改链接属性。扫描及摘要在 blocking worker 中完成。
- 通过已核对的文件/目录描述符，仅移除 com.apple.quarantine。处理前再次核对对象身份和当前属性；不使用递归 shell 命令，不修改其他属性、文件内容或签名。完成后回读整包清单及属性，只有全部匹配预期才返回成功。
- 单次执行失败时，尝试将已处理对象恢复为原隔离属性，仅对身份仍相同、属性未被他人改写的对象恢复。不能完整恢复则明确报 QUARANTINE_ROLLBACK_INCOMPLETE，保留证据，不声称成功。

## 记录与失败

使用现有 operation_log 的 installation.quarantine 事件，记录 running、succeeded/failed 与错误码，不新增数据库迁移或后台服务。

属性记录位于元数据目录 installation-security/<plan-id>/，新目录为 0700，记录文件为 0600。before.json 保存范围、整包清单摘要、对象身份及变更前属性字节；确认其文件和目录链接已同步后才开始移除属性。result.json 记录结果、时间、数量和错误。

它不是存档备份，也不保存游戏文件原始内容。进程/系统中断可能留下部分属性状态与没有 result.json 的记录；不会自动补做、自动启动或推断成功，需要人工核对。记录失败同样返回结果未知的说明，不能把数据库日志写入失败当成文件未变更。当前不提供独立的一键属性恢复入口；执行失败时的即时恢复由同一动作完成，原属性记录始终保留供核对。

Hub 配置重置不删除这些安全属性记录。旧确认不传播到新安装或更新后的程序，binding_status、普通启动互斥、配置发布保护和恢复到新目录的规则保持。

## 自动回归

覆盖仅变更目标属性并保留文件字节/其他属性、注入移除失败后的即时恢复、过期或未确认时无写入、内容/属性/根身份变化、外部链接和硬链接拒绝、未知样本、活动/未知游戏会话、元数据范围重叠，以及 UI 取消、重新勾选、失败不自动重试及成功不自动启动。

真实安全属性变更仍需针对指定 QA 安装的操作时确认；合成属性测试不能代替真实游戏验收。
