# 实例资源安装后配置

资源来源库部署到明确实例后，在同一资源卡保留本次任务和预览目标。轮询现有任务列表，只有持久化成功且entry_id、payload_root、manifest_sha256与预览一致时开放“配置此实例”。失败、取消、状态记录未完成或找不到任务时不进入下一步。

点击后按原实例ID重新读取配置，核对登记实例、安装ID及数据根仍与预览一致；报告实例ID/根也必须匹配。打开既有配置对话框，复用资源发现、内存比较、服务端预览、保护备份、应用和回滚，不自动启用资源、不修改已有世界。

本次连续入口属于当前页面的安装会话；离开模块/重启后仍保留原任务记录，可从实例配置入口选择实例重新读取，不新增迁移表、后台任务或路径推测关联。安装完成文案只表示文件复制/校验，不认证实际游戏加载或声音播放。

如果游戏尚未产生默认模组配置，继续要求先在游戏内保存默认组合；不可用未知空基线绕过现有配置保护。声音使用已有options.json；不可读时按现有规则拒绝替换。新配置目标与安装目录由服务端控制，连续入口不授予额外文件权限。
