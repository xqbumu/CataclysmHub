# 实例资源受控部署

日期：2026-10-29。范围：将已经登记的单个本地模组/声音包复制到明确实例，不更改游戏安装、配置或世界文件。

## 用户流程

1. 下载、校验和解压资源；合集须分别登记需要的单个资源根。
2. 模组与声音 → 资源来源库 → 部署到游玩实例。目标列表同时显示实例、关联游戏和版本。
3. 后端生成实例绑定的部署预览，显示来源、暂存目录、最终资源目录、字节范围及摘要；用户核对后确认。
4. 任务完成后，在实例配置重新读取资源，选择新世界默认模组或声音包，再走配置预览、保护与应用流程。声音切换后重启游戏。

部署不写配置，但已有配置若已经引用相同 ID，下次游戏启动可能加载新增资源。文件未变化不代表旧世界加载结果必然不变；仍需在独立实验世界验证兼容与声音播放。已有世界增删模组、资源升级/卸载和跨版本迁移不在此操作中。

## 实现与约束

复用 `ContentInstallPlan`、原有资源复制 worker、任务表、请求幂等、取消和结果补记录；没有新增数据库迁移或调度层。新 `InstanceContentInstallPlan` 仅为预览增加实例 ID、名称和安装 ID。前端不提交目标路径；后端根据实例记录计算目录。

- 发布目标为 `实例/mods/hub-计划UUID` 或 `实例/sound/hub-计划UUID`；完整文件先写入 `实例/.hub-content-计划UUID/data`。
- 预览不创建目录。确认前核对实例根、关联安装及程序摘要，复用占用门和原路径身份检查；活动或未知游戏会话以及其他文件任务不能绕过互斥。
- 扫描实例用户资源与安装内置资源。扫描不完整、重复 ID、源包内部重复 ID 或嵌套资源根均拒绝；合集不被隐式拆包或全部启用。
- 复制前后核对完整清单、源和目标字节；链接、特殊文件与硬链接继续拒绝。受控发布前再次扫描重复 ID，并串行化取消边界。
- macOS/Linux 用目录句柄及 `renameat_with(NOREPLACE)` 发布完整目录，不覆盖已有目录或链接；跨文件系统重命名失败会保留暂存。目标资源角色目录不跟随链接。
- 发布前失败保留未完成标记，候选扫描范围之外的暂存不被当作资源。发布后若同步或状态落盘失败，可能留下已发布的完整目录；任务保持失败/待恢复，不能据此断言资源未发布，也不能自动重放。
- 暂存容器保留文件清单、核验记录及目标实例引用。成功任务仍标记兼容性未验证，必须重新读取目标实例配置，不自动修改世界组合。

当前 Windows 和其他平台的发布入口在后端明确拒绝，现有独立资源库复制继续可用。Linux 使用相同实现但本轮运行证据来自 macOS，不能当作 Linux 平台验收。外部程序仍可自行修改文件；本机制不是系统沙箱。

## 验证边界

新增回归覆盖声音/模组发布、目标实例隔离、预览只读、确认与幂等、重复 ID 在确认时重检、活动会话拒绝、链接角色和程序变化拒绝、已存在发布目标不被覆盖、失败暂存不被发现、世界与默认配置保持原字节及嵌套包拒绝。前端回归覆盖目标选择、确认前不执行、请求绑定及错配响应拒绝。

本轮没有执行真实游戏、修改玩家实例或播放声音；测试使用临时目录与合成资源，资源被 Hub 发现不代表游戏实际加载成功。
