# 本地模组与声音包资源库

日期：2026-10-28。对应 MOD-001、MOD-003、MOD-005 与 WP-12 的本地元数据登记切片；不是完整的安装／启用实现。

## 已实现

从本机目录选择器选择单个包并登记，读取 `modinfo.json` 中的一个或多个 `MOD_INFO`，或 `soundpack.txt` 中的 `NAME`、`VIEW`。支持字符串和 `{ "str": "..." }` 形式的模组显示名。模组依赖未声明时保留未知，与显式空数组区分；可显示字符串版本声明。字段取自本地包，不代表经过验证。

资源库保存在元数据 SQLite schema 11 的 `content_entry` 中，同一规范路径和类别复用登记 ID，允许不同路径的重复资源 ID 并展示提示。刷新重新读取描述文件；读取失败保留上次成功快照和时间，并标识错误，历史快照不参与可用依赖集合。移除登记只删除数据库记录，不删除资源文件，不修改世界或游戏配置。登记、刷新、移除与操作日志使用同一事务，审计失败回滚元数据变更。

只读描述文件以目录能力句柄打开，拒绝描述文件符号链接及非普通文件，非阻塞打开避免 FIFO 挂起；读取上限 1 MiB，单包最多 256 条定义、单定义最多 256 个依赖，资源库最多 1000 个登记。目录下的 JSON／音频文件不遍历、不执行。描述文件 SHA-256 仅标识读取字节，不是完整包摘要或来源真实性证明；外部工具仍可改变文件，列表不是实时快照。

## 游戏语义与边界

模组组合属于世界配置；声音包的发现与设置选择另有游戏规则。登记不等于安装、启用或已绑定实例。兼容性、上游来源、许可证与未提供的版本均保留未知／未验证。依赖提示仅说明在此资源库未找到，不能推断目标游戏缺少内置 `dda`。重复 ID 提示不自动选择覆盖。暂未进行依赖环检测或解析完整冲突图。

操作只读包描述文件并更新 Hub 元数据，可在游戏运行时使用；不参与文件修改准入，不修改候选包指纹或实例存档。安装／启用不能复用这一豁免。

解析依据：[CDDA 0.H MODDING](https://github.com/CleverRaven/Cataclysm-DDA/blob/0.H/doc/MODDING.md)、[CDDA 0.H SOUNDPACKS](https://github.com/CleverRaven/Cataclysm-DDA/blob/0.H/doc/SOUNDPACKS.md)。这里只实现元数据子集，不据此宣称所有分支、版本或声音包可加载。

## 后续开发与验收

1. 面向明确游戏安装／版本建立资源发现范围，补齐上游声明、许可证、完整包清单与摘要。
2. 本地包安装先预览源／目标、重复 ID、依赖和影响实例；复制至独立目录、校验发布，不覆盖自定义文件。复用既有任务生命周期与范围检查。
3. 模组启用先支持新建实验世界的组合；已有世界的增删模组要展示存档影响、保护点及配置差异。声音包按已验证版本的设置格式绑定，保留未知配置字段。
4. 升级、卸载在世界／环境档案引用检查与保护流程就绪后开放；远端下载单独实现，不直接执行来源包内容。

测试覆盖多定义／翻译名／缺失依赖声明、声音描述格式、超限与符号链接拒绝、持久化及刷新失败、移除不删文件、审计失败回滚、schema 10 升级备份与失败回滚，以及界面登记／取消／重复 ID／历史数据提示。真实游戏资源加载、声音播放及存档影响尚未验收。
