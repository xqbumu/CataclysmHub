# 模组与声音包候选发现及依赖诊断

日期：2026-10-28。状态：只读实现；不认证游戏加载或存档兼容。

## 观察契约

沿用实例配置报告入口，读取四个候选范围：实例 `mods`、`sound`，安装工作目录下 `data/mods`、`data/sound`。已知 macOS `.app/Contents/MacOS` 布局转换至同包 `Contents/Resources`。这些只是默认位置候选，不根据未知安装版本推断自定义 datadir、basedir 或构建前缀，不声称覆盖游戏最终搜索路径。

各范围分别记录来源、绝对路径和状态；递归读取 `modinfo.json` 或 `soundpack.txt`，复用资源库解析器，展示定义、依赖声明、版本声明和元数据摘要。报告不扫描音频或游戏内容字节，不启动游戏，不写文件，不改变绑定或会话状态，无新数据库表。资源库登记快照仍单独展示，登记目录不会自动进入候选资源索引。

## 诊断语义

- 同种资源重复 ID 保留全部路径并报告歧义，不推演覆盖赢家。
- 唯一模组声明的依赖在候选索引中未出现，报告“本次未发现”；多个候选报告歧义。没有 dependencies 字段表示未知，不等同显式空列表。
- 对唯一且明确声明依赖的模组构建有界图，以迭代遍历发现循环；不根据未知或重复定义建立确定依赖边。
- 配置引用未出现、依赖未在该默认／世界列表声明分别提示。后者不自动插入或排序，不认定游戏一定拒绝加载。
- 无诊断项不等于依赖验证通过；不处理废弃 ID 替换、动态内容加载、版本兼容规则或已有存档迁移。

已有世界的模组组合影响地图、物品和角色数据，不能仅凭 ID 可见就安全增删。声音包存在也不证明声音开关已启用或游戏已成功播放。

## 边界与并发

能力目录句柄逐级 nofollow，跳过链接与特殊文件；每个范围结束复核根目录身份，变化时丢弃该范围包记录；整个报告结束复核实例根。游戏可同时修改内容，因此报告不是一致性快照，也不是后续写入的确认凭据。

每次发现最多枚举 20,000 项、读取 16 MiB 元数据、接纳 2,048 个定义；单文件最多 1 MiB、单包最多 256 定义、单定义最多 256 依赖。递归深度最多 8，诊断最多 2,048 项。超限／不可读／损坏／路径异常明确标记不完整，已读候选可保留；缺失目录单独标记，不据此认证资源不存在。配置文件读取预算与上述发现预算分别计算。

## 验证与后续

合成目录回归覆盖用户及安装候选、嵌套包、声音包、重复 ID、依赖缺失／未知／循环、配置缺少依赖、外部登记不等于发现、链接拒绝、损坏与大小／深度上限。真实游戏加载与声音播放仍需人工验收。

已增加[内存草稿与配置差异预览](content-config-preview.md)及保护点要求；后续实现服务端变更预览与受约束的写入确认；已有世界增删与跨版本迁移仍需独立的存档影响方案。本切片不提供启用、卸载或升级动作。
