# 实例数据根完整备份

状态：已实现；数据库 schema 9。对应 USR-001 的实例保护基础，不表示按范围并发已经通过。

## 来源与预览

“独立备份”新增备份来源选择：工作区存档根或已登记实例。实例预览 IPC 只接收实例 ID，服务端解析已登记的安装与数据根；调用者不能提供任意源路径或验证状态。实例根必须通过既有目录分离/树边界检查，来源 ID 和登记安装摘要也须符合可读归档契约。非法来源记录在计划阶段返回 INSTANCE_CONTEXT_INVALID，不写临时目录。

实例范围是整个 InstanceDataRoot，包含 save、config 及其中其他普通文件/空目录。它不是只备份 save 子目录，不包含安装目录、安装共享缓存或根外 HOME/临时目录。链接、特殊文件、不可读或超出扫描预算均中止，不静默跳过。安装摘要是登记快照，不是本次程序版本探测或兼容性证明；安装本体不必被执行。

预览显示完整源/目标、条目、容量和尽力快照说明；取消不创建任务、归档或操作审计。单次计划摘要包含来源与实例快照。计划分别持有源和备份目录的物理身份句柄；执行时对实际打开的目录能力句柄核对，预览后相同路径/相同文件清单的目录替换仍拒绝。源、备份、元数据范围改用物理祖先关系检查。

## 执行、记录和占用

沿用已有冻结副本、源二次核对、流式 tar/zstd、SHA-256、独立校验、受控发布、取消和失败恢复协议。创建/校验任务及归档新增可空 play_instance_id、source_root；旧历史保持空值，不推测其归属。来源与创建意图/审计、归档与终态/审计分别在既有事务中提交。同请求重试不重放文件操作。

创建实例备份的资源读取声明指向实际实例根，旧记录回退工作区根。当前活动游戏/未知会话和文件任务仍全局互斥，未因来源可分离而提前允许并发。重新校验继承原归档的来源关联，并核对记录与清单是否一致；源实例离线不妨碍读取独立归档。

## 独立归档与兼容性

工作区备份继续生成 manifest v1/save_root；实例归档生成 v2/instance_data_root。receipt 仍是 v1，tar/zstd 文件布局不变。v2 的 source_token 是实例 UUID；extensions.instance_source 含实例 UUID、安装 UUID、登记程序 SHA-256 和 binding_verified=false；boundary_verified=false。清单不写本机源绝对路径。

当前 v2 限定 best_effort，未支持的语义字段不能伪装为已验证的世界、档案、角色或兼容结论。来源上下文缺失、无效、与 source_token 不一致、擅自提升验证状态或未知版本均拒绝。旧 reader 不理解 v2 时必须拒绝，不能降级当作 save_root；本版继续校验/恢复 v1。

JSON 契约见 [v2 schema](../contracts/backup-manifest-v2.schema.json)、[合成示例](../contracts/examples/backup-manifest-v2.json)。source_token 与 instance_source.instance_id 相等是额外语义检查，JSON Schema 不替代 Rust 的文件、摘要、计数和预算检查。

独立校验/新目录恢复无需原数据库或安装。恢复仍生成新容器 data/，不会自动绑定成可启动实例，不恢复游戏安装、不覆盖原实例。绑定验证、游戏加载兼容及原实例是否静默分别判断。原始目录不用删除或清空。

## 迁移及保留规则

schema 8 升级前通过现有 VACUUM/quick_check/fsync 协议保存副本，事务内增加任务及归档各两列；失败回滚并保留原版本及副本。旧版本应用必须拒绝更高 schema，不直接回降数据库。

已有保留预览只处理工作区 save_root 归档，实例归档明确排除并提示，不将不同实例混在同一“最近份数”或最后有效点规则中。实例保留规则、删除和自动检查点未开放。名称、备注、锁定、新目录恢复及字节检查仍可用于实例归档。
