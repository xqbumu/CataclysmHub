# 上游版本目录、资源下载与紧凑布局

日期：2026-10-29。依据：[联网调研与一手来源](../research/releases-resource-downloads-2026-10-29.md)。

## 用户入口与来源

- 游戏库 → 获取游戏：DDA、Bright Nights、The Last Generation、Era of Decay、There Is Still Hope。读取各项目自身的 GitHub Releases，展示最近 30 个发布，并补入 latest 非预发布入口（若不在列表中）。这不是完整历史，也不是平台兼容认证。
- 模组与声音 → 下载资源：CC-Sounds 发布附件、Kenan DDA 历史发布包、Kenan BN 固定提交 ZIP。DDA 合集明确标停更；BN 分支先解析 master 的 commit SHA，再下载 SHA 固定地址，避免分支移动改变既定目标。
- 可按附件文件名筛选版本、系统和架构；不以文件名猜测替用户自动选择资产。保留 macOS DMG、ZIP、tar.gz 等原始格式。模组 version 字段不转换为跨游戏兼容规则。

## 首次同步及手动更新

桌面首次启动按游戏来源尝试同步；资源来源首次进入时尝试同步。每个 source 的 attempted 在网络请求前落盘，之后重启、切页或重挂载只读缓存。首次离线失败也不自动重试；点击“更新版本”才重新获取。成功更新时间、旧列表和失败原因同时保留，不定时刷新，不自动下载附件。

目录放在现有元数据根的 remote-catalog.json，独占临时文件写入、同步文件后重命名替换。目录损坏或无法读取时关闭远端功能并显示错误，已有本地工作区仍可打开；不会为了恢复目录而删除既有数据。此缓存与下载记录不属于启动偏好重置范围。

公开 GitHub API 不使用用户令牌。同步请求有 45 秒上限，响应体 8 MiB 上限，提交响应 2 MiB 上限。限流及其他 HTTP 错误返回界面，由用户手动重试。当前没有完整历史分页、ETag、自动重试或后台更新调度。

## 下载与管理

确认时固定 source ID、release tag / commit 和 asset ID，后端只接受内置来源及已缓存资产，不接受任意 URL 或用户指定输出路径。验证 HTTPS、仓库路径、附件名称和可用 SHA-256；重定向限制为 GitHub 官方下载域名。发布资产校验预期大小，分支 ZIP 大小未知但仍有 2 GiB 总量上限；下载整体超时 20 分钟。

文件放入系统托管根 downloads/{uuid}/，以 download.partial 独占创建并流式写入；长度及上游摘要（若提供）通过后发布原始文件名。保存来源仓库、URL、资产 ID、版本/提交、时间、大小、本地 SHA-256、上游摘要匹配状态及路径。没有上游摘要时明确只记录本地摘要，不宣称来源真实性认证。

一次执行一个下载，同步与下载串行；进度读取及取消独立于目录锁。界面显示接收大小，允许取消网络等待或接收。失败/取消尽力移除 partial，不写成功记录；进程被强制终止时可能遗留 partial/空目录，不自动续传或清理。若文件发布成功但目录记录落盘失败，文件会保留并返回错误，不能将该情况报告为已登记成功。

“删除下载包”需确认，只按记录中的 UUID 和受验证文件名删除原始包；不使用显示绝对路径作为删除依据，不递归删除目录，保留同目录内已解压文件。目录链接拒绝；文件链接只解除链接。下载记录是下载时的证据，不持续扫描磁盘或证明文件当前未变化。

下载不自动解压、执行、导入安装或启用模组。游戏包需按系统解包/挂载后通过现有游戏导入入口登记；资源包解包后选择直接包含 modinfo.json 或 soundpack.txt 的单个包目录登记，再走已有实例配置与保护备份流程。合集不自动全部启用，已有世界不自动变更。保留原始归档也保留其中上游许可证和 credits 文件。

## 信息密度

全局收紧页边距、标题间距、面板、统计卡、实例卡与分区间距；保留 40px 单行交互控件。版本使用可折叠紧凑行，展开后附件名称、大小、校验方式和下载操作同排展示。修复旧 file-path 的 9px !important，使路径和附件名称可读；附件名称为 13px，窄窗口自然换行。
