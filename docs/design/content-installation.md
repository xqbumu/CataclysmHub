# 资源包安装到独立目录

日期：2026-10-28。状态：本地资源副本安装实现；不等于游戏启用或版本兼容验收。

## 用户流程

在内容资源页选择已登记且最近读取正常的模组／声音包，点击“安装到独立资源目录”，选择现有父目录。预览完整来源、随机唯一目标、条目数／字节数、整包文件清单摘要及限制，勾选后确认。任务后台复制与校验，可取消、刷新状态，重启后保留历史。成功副本在 `content-<plan-id>/data/`，用户可通过现有登记入口将该目录加入资源库。

这是复制到独立资源库的安装步骤，不写入游戏的 mods/sound 目录，不修改世界的 mod 列表或声音设置，不启动游戏。界面与操作日志不把安装标作启用。版本／依赖／冲突仍须在后续目标游戏绑定前核对；本轮不引入未经验证的版本适配器。

## 目录与完整性约束

- 复用安装复制器的受限目录枚举、能力目录句柄、普通文件读写和 SHA-256 流式校验；不伪造游戏可执行文件或游戏安装记录。
- 源包和目标父目录必须独立；目标父目录不能与元数据、游戏安装、实例、存档、备份目录重叠，也不能位于已登记包内。允许在独立资源库中创建多个并存容器。
- 准入沿用全局文件任务保护，预览和确认均检查：普通／未知／候选游戏运行中都不执行此安装；任务执行时阻止启动与其他文件任务。资源登记本身仍可只读进行。
- 最多 20000 项、64 GiB、32 层目录；不复制链接或特殊文件，Unix 同时拒绝硬链接。仅保留普通文件字节和目录结构，不保留权限、时间戳、所有者、ACL、扩展属性。
- 源描述文件须与登记摘要一致；确认后先重扫源包，逐文件复制并验证字节数及摘要，再重扫源和目标，检查持有目录的物理身份。任何不一致均不发布完成标志。现有目标绝不覆盖或合并。
- `content-manifest.json` 是排序的路径／类型／大小／文件摘要清单；`content-verification.json` 记录清单 SHA-256、计划身份、`data` 路径和验证时间。该证据描述完成时字节一致，不证明内容可信、可播放、可加载或将来未被更改。

## 生命周期

schema 12 `content_install_task` 持久保存任务身份、请求摘要、来源登记、源／目标、清单摘要、状态与错误。开始意图与操作日志先提交，再启动 worker。相同请求键与参数返回原任务，不重放复制；同键不同参数拒绝。

目标容器先创建 `CONTENT_INSTALL_INCOMPLETE`，仅在源／目标核对、清单／校验记录写入与同步完成后移除。失败／取消留下现场，不删除源或未完成目录。取消与发布通过既有 mutation 门协调；若完成发布已经先于取消，结果仍可能成功，取消不撤销已完成副本。

worker 结束后终态与审计同事务。终态记录失败复用 `recovery_required` 及内存覆盖；释放已经结束的文件任务占用，重试只补记录、不重放 I/O。重启时 running/cancelling 标记中断，不将现场自动当作成功，也不自动重试安装。未完成副本不自动登记。

## 验收边界

合成资源验证确认／幂等、源变化、既有目标、父目录替换、活动游戏保护、链接拒绝、已登记包保护、发布边界取消、审计失败、终态补记录不重放、重启不重放及 schema 11 迁移。界面验证预览确认、取消预览、取消任务与中断状态显示。

真实模组加载、声音播放、目标游戏配置绑定、世界兼容性、跨平台文件系统认证、远端下载与卸载不在本切片通过范围。下一步是有版本证据的资源发现／配置读取和只读影响预览，然后才开放实验世界模组组合及声音设置写入。
