# 实例配置草稿与只读差异预览

日期：2026-10-28。状态：本地草稿已实现；服务端变更计划、保护副本和确认写入未实现。

## 范围

在实例配置报告内比较新世界默认模组、声音包 ID 与声音开关。草稿仅在组件内存中存在，关闭报告即丢弃；基于报告的读取时间与候选元数据，不发起新的文件读取、启动或写入请求。报告本身不是一致性快照，预览不是可执行计划或确认凭据。

默认保持全部字段原声明。用户显式选中某一项后才参与比较；默认模组按每行一项输入，去掉行首尾空白和空行，保留顺序，不去重或补齐依赖。空列表表示拟声明空组合，不表示“恢复游戏默认值”。声音包不能为空；声音开关提供保持、true、false 三种选择。

原文件读取失败、缺失或声音字段未声明时显示原值未知，不用空值或游戏默认值替代。字段差异保留前后声明和文件路径；默认列表重排也是差异。无效或重复模组输入不产生该字段差异，其余有效字段仍可比较；错误提示与字段差异同时展示。编辑任何输入都会使旧结果失效。

只比较 `config/user-default-mods.json` 的 dependencies 和 `config/options.json` 的 SOUNDPACKS／SOUND_ENABLED；已有世界 `save/*/mods.json` 不可编辑。不生成完整 JSON 替换内容，不丢弃未知字段。

## 草稿诊断

使用候选资源索引检查未知／重复 ID、未声明依赖、草稿缺少的直接依赖，并展示涉及所选模组的既有循环观察。登记资源库不等于候选可见。扫描不完整时保留提示，不选择覆盖来源、不重排列表、不推断废弃 ID 替换或版本加载规则。

最多 256 个模组 ID，每个 ID 限 1–256 UTF-8 字节且不含控制字符；声音包 ID 同限。诊断最多展示 256 项，超限加明确提示。无诊断项不表示依赖、游戏加载或存档兼容通过。

## 保护要求与后续执行门槛

界面说明后续写入至少需要目标游戏退出、重新读取并核对文件及资源，以及可验证的原配置文件保护副本；涉及已有世界／版本迁移还需存档备份与恢复验证。本切片不创建、验证或认证这些保护点，也不解除任何会话或任务保护。

后续应先在独立实验实例实现服务端预览与明确确认，再加入有原字节保护、变化检测与失败恢复的有限写入。已有世界模组增删、升级／卸载和跨版本迁移另行设计，不复用本地草稿作为授权。

## 验证

前端回归覆盖保持原声明、显式空列表、仅顺序变化、缺失原值、草稿变更使旧预览失效、重复／超长／控制字符／数量超限输入、候选歧义、缺少依赖、循环观察和诊断上限。没有真实游戏操作，未验证新世界创建或声音播放。

## 后端重新读取预览（2026-10-28 补充）

已增加 `preview_content_config(instance_id, input)`：输入仅允许默认模组 ID 列表、声音包 ID、可选布尔声音开关，不接受任意文件路径或已有世界目标。ID 在后端重新校验（数量、UTF-8 长度、控制字符和重复）。客户端明确点击后才调用，编辑期间返回的旧请求结果丢弃。

在原 mutation 门内重新观察实例配置和候选资源，并再次读取拟修改文件，比较其 SHA-256 与本次报告。持有实例根句柄并在结束时复核路径身份。原文件缺失、损坏、重复 JSON 对象键、格式不支持、声音字段未声明或两次读取摘要不同均拒绝生成替换内容。只有原文件可读、拟修改字段存在时，才按已观察格式生成 JSON；无语义差异不生成文件。未知字段的解析值保留，但格式、空白和对象键顺序可能归一化，不声称字节级保留。

返回新报告、拟变更文件路径、原字节摘要、拟生成 JSON 及其摘要、针对草稿引用的候选诊断。单文件输出不超过 1 MiB，只生成已存在的默认配置或 options；已有世界不进入替换清单。保留诊断并不阻止只读预览，也不表示草稿可安全加载。

`write_supported` 固定 false，无持久计划、确认令牌、保护副本、审计写入或文件修改。允许运行中只读观察，mutation 门不能阻止游戏改文件；报告与第二次读取不是事务快照，不能作为未来写入凭据。关闭后端预览即丢弃，后续写入必须重新获取并校验独立执行计划。

后续确认写入尚待实现：目标静止与资源占用检查、原字节保护副本及校验、同目录发布前复查、失败／中断后可见恢复状态。不能仅复用当前 JSON 或摘要直接覆盖目标。

## 原字节保护备份接入

已增加[配置保护备份](content-config-protection.md)入口，复用整个实例备份：重新生成配置预览并将原摘要固定为备份复制的校验要求，单独确认后创建可独立校验的归档。备份成功不应用草稿、不提升 `write_supported`；当前仍无配置写入或原地回滚接口。界面明确展示整个实例范围，并保留任务记录、刷新与取消入口。

## 单文件应用入口补充

只读 `ContentConfigPlan.write_supported` 继续为 false，不能直接传入写入命令。另有[单文件应用准备与确认](content-config-application.md)入口，需要选定保护备份、重新校验并生成独立短期计划。一次仅修改一个有差异的配置文件，已有世界不受理；中断保留全局保护并提供只读核对及明确解除。
