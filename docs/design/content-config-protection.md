# 配置变更前的实例保护备份

日期：2026-10-28。状态：已接入原字节保护备份；配置应用未实现。

## 选择与范围

复用已有实例备份，不增加配置专属归档格式、任务表或调度层。备份包含整个实例数据根的配置、存档和其他普通文件，不包含安装目录。这个范围可能大于拟修改的配置文件，界面必须展示来源、目标备份根、文件数、总字节、所需空间和尽力快照说明，并取得单独确认。用户仅打开报告或查看后端配置预览不会启动备份。

后台原有复制、全清单比对、TAR/Zstandard、回读验证、取消、中断记录、幂等请求和新目录恢复机制保持适用。保护仅覆盖文件字节，不认证游戏语义、版本兼容、声音播放或全部权限元数据。

## 准备与确认

`prepare_content_config_protection(instance_id, input)` 首先重新生成后端配置预览；没有差异时拒绝创建此用途的备份计划。随后调用实例备份预览，核对实例 ID、来源根及拟修改配置的相对路径、普通文件类型，再将配置预览原 SHA-256 固定为备份条目的预期摘要并纳入计划摘要。路径或类型不匹配时丢弃计划；复制阶段计算原字节摘要并核对预期，不匹配就拒绝发布备份。普通备份预览不计算完整内容摘要，仍沿用原行为。

准备步骤不创建归档。用户确认整个实例范围后，复用 `create_backup`，保留同一请求键重试不明确的响应；备份任务确认及执行时重新检查资源占用、路径身份、完整源清单和原字节。当前目标实例运行、未知会话或冲突文件任务仍由已有准入拒绝；独立候选游戏运行时是否可备份由已有目录范围检查决定。

由于配置准备和备份准备分别持有 mutation 门，本次对照不是事务快照；创建过程仍必须依据备份计划执行完整源核对。配置应用始终 `write_supported=false`，不会因备份成功自动写入。

## 展示与生命周期

界面提供确认创建、手动刷新和取消，显示任务 ID、阶段及终态。关闭报告或编辑草稿不会撤销已经发出的备份任务；记录保存在备份页，后续可重新校验、锁定保留或恢复到独立目录。失败／取消／需要恢复的任务不显示为已建立保护。

成功只说明该次实例归档已完成，不能把历史成功当成未来写入的授权。备份仍受既有保留策略管理，也可能被外部删除或损坏。后续配置应用必须重新校验归档、核对来源身份及目标配置摘要，并制定原地变更失败恢复流程；现有恢复入口只恢复到新目录。

## 验证

集成回归验证：预览无任务或归档副作用；确认要求；配置原摘要固定到备份清单；重复请求不创建第二任务；归档独立校验后恢复出完全相同的配置字节及存档；预览后同大小改写配置拒绝发布有效备份；无差异和未知会话拒绝。界面验证明确确认、幂等重试、状态刷新与取消。全部使用合成目录，不操作用户正在游玩的游戏。
