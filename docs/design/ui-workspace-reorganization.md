# 工作台 UI 重组（2026-10-29）

结论：按用户任务重组导航和页面，把日常操作、诊断、配置变更与历史记录分层，保留明确的风险提示和执行确认。

## 审查与处理

本轮为信息架构和交互重构；没有据此认定游戏兼容性或多版本并发已验收。

| 优先级 | 现象与影响 | 原因判断 | 本轮处理 |
|---|---|---|---|
| P0 | 未发现此次 UI 重组新增的确认绕过；原有文件写入仍必须经预览与明确确认 | 安全行为由已有工作流和后端计划共同约束 | 保留启动、备份、恢复、配置应用、回滚确认及异常提示 |
| P1 | 游戏库混合安装、实例、复制和记录，用户难以判断操作对象 | 按功能增长叠加组件，缺少任务层级 | 分成游玩实例、安装版本、安装复制三个分区 |
| P1 | 配置弹窗堆叠声明、诊断、草稿和历史，滚动距离过长 | 读取和写入工作流没有分层 | 当前配置、资源诊断、修改配置、应用与回滚四个分区；固定弹窗标题及关闭入口 |
| P1 | 世界发现与备份分别位于顶级导航，存档保护路径分散 | 导航与内部模块一一对应 | 合并到存档与备份，内部保留独立备份、世界与角色 |
| P2 | 首页宣传性内容、装饰和占位指标干扰判断 | 初始页面偏展示用途 | 改为真实数量、常用任务入口、资源占用和最近记录 |
| P2 | 表单、按钮、长路径、JSON 的阅读节奏不一致 | 多轮功能各自扩展样式 | 统一控件、间距、折叠详情和滚动边界 |
| P2 | 模组与声音包列表缺少查找方式 | 仅支持顺序浏览 | 增加名称/ID 搜索和资源类型筛选 |

## 信息架构

| 一级入口 | 内部结构 | 主要用途 |
|---|---|---|
| 总览 | 真实计数、初始工作区设置或常用入口、占用、最近操作 | 决定下一步 |
| 游戏库 | 游玩实例 / 安装版本 / 安装复制 | 先选游玩对象，再管理程序 |
| 存档与备份 | 独立备份 / 世界与角色；保留策略按需展开 | 发现、保护、核验与恢复 |
| 模组与声音 | 资源登记、搜索、类型筛选、安装任务 | 管理本地来源，区别登记、安装与启用 |
| 任务与记录 | 当前占用、配置应用与回滚记录、操作日志 | 查任务和追溯变更 |
| 设置 | 工作区路径与现有设置 | 低频管理 |

实例配置仍从具体实例进入；资源库不充当全局“启用模组”开关。已有世界的模组声明、新世界默认声明和声音设置分别展示，读取成功不等于游戏实际加载成功。

## 交互与安全边界

- 分区首次访问才挂载；在同一页面内切换后保留组件，避免草稿和任务观察状态被丢弃。切换一级页面、关闭弹窗或重启不提供新的草稿持久化保证。
- 分区支持左右方向键、Home/End、选中状态和面板标签；窄屏隐藏导航文字时保留其无障碍名称。
- 路径、摘要、完整拟写入 JSON、低频策略采用展开详情；变更目标、阻断条件、风险提示和最终确认保持在相应操作流程中。
- 扫描截断提示保留在配置窗口上方；拟配置诊断发现问题时默认展开。
- 保留后端一次性计划、保护副本、锁和恢复机制；本轮不改 Rust/IPC、数据库、存档或游戏配置。

| 类别 | 当前值 |
|---|---|
| 字号 | 正文 14px，页面标题 28px，导航 14px；正文行高 1.6 |
| 间距 | 控件 8–12px，组间 16–24px，桌面主区水平 32px |
| 色彩 | 背景 #111715，面板 #1a221f，抬升面板 #222d28，正文 #e9efeb，次级 #a6b5ac，边线 #35433b，主操作 #c1dea3 |
| 圆角 | 面板 12px，常用控件 8px |
| 网格 | 侧栏 204px，主区最大 1440px；资源列表两列，窄屏一列；小于等于 760px 侧栏收为 64px |
| 弹窗 | 普通 680px、配置 1000px 上限；内容内部滚动，标题与关闭入口固定 |

## 已落地的快速改进

1. 首页减少装饰性模块与未实现入口。
2. 游戏库默认进入游玩实例。
3. 配置读取、诊断、修改和记录各有清晰入口。
4. JSON 与低频目录详情按需查看。
5. 模组与声音包支持组合搜索/筛选。
6. 共用分区组件与基础控件样式，避免引入路由或状态管理框架。

## 验证与证据

- `npm run check`：格式、类型检查、12 个测试文件 / 88 项测试、生产构建通过。
- 新增验证：分区懒加载、键盘导航、受控导航后草稿保留、资源组合筛选不修改登记数据。已有启动/备份/恢复/配置确认测试继续通过。
- 浏览器检查实际 React 界面：双版本合成安装、两个合成实例、长路径、缺失声音设置、损坏世界声明。仅操作导航和只读配置窗口。
- 900px 下存档与备份、模组与声音、任务与记录、设置均无页面横向溢出；390px 游戏库压力检查宽度与 scrollWidth 均为 390。
