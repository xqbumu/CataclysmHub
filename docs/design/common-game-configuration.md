# 集中游戏配置与获取流程

日期：2026-10-30。适用：开发预览。

## 集中入口与范围

设置页和模组与声音页复用按安装/实例选择器；读取后在当前配置查看通用项，在修改配置编辑。游戏语言与 Hub 界面语言是不同设置，本次集中的是游戏选项，不新增 Hub 翻译或全局覆盖模板。每次仅处理明确选择的实例，不批量改写已有实例。

首批通用项集中声明于前端 `gameOptions.ts` 和后端 `game_options.rs` 的受控白名单：

| 项目 | 游戏键 | 写入范围 |
|---|---|---|
| 游戏语言 | USE_LANG | 系统空值，以及界面列出的常用语言代码 |
| 自动保存 | AUTOSAVE | true/false |
| 游戏回合间隔 | AUTOSAVE_TURNS | 整数 10–1000 |
| 现实分钟间隔 | AUTOSAVE_MINUTES | 整数 0–127 |

依据为 [CDDA 0.H options.cpp](https://raw.githubusercontent.com/CleverRaven/Cataclysm-DDA/0.H/src/options.cpp) 和 [CDDA 0.I options.cpp](https://raw.githubusercontent.com/CleverRaven/Cataclysm-DDA/0.I/src/options.cpp)。游戏自动保存同时受两种间隔约束，取较大间隔；不是两种计时任一到达便写盘。自动保存由游戏实现，Hub 不因该开关建立备份或声明存档一致。

这不是所有变体的格式认证。只读取目标 options.json 中已存在的字符串声明，字段缺失、重复、损坏或值类型不支持时拒绝推断/创建。可用翻译仍取决于发行包；界面显示的语言代码不证明该包已携带翻译。保留未列出的现有语言时不要勾选该项。

## 修改与恢复

每项需主动勾选，未选项保持原值；勾选后值未改变的通用项也不参与提案，避免未列出的现有语言被无意义地送入写入校验。系统语言的空字符串是明确值，不能当作缺失。`ContentConfigInput.game_options` 为可选白名单映射，旧调用可以省略。后端验证键、布尔、语言和整数范围，重新读取文件并保持其他字段。

只修改通用项时不以无关资源扫描告警阻断；资源观察仍保留在原报告。涉及声音或默认模组时保留原有资源诊断门禁。

通用项与声音写在同一 options.json，允许同一次单文件变更；与默认模组文件同时有差异时仍需分别执行。复用已有新鲜预览→配置保护备份→单文件发布确认→历史核对/原字节回滚；活动会话和身份变化等原有门禁保持。不会启动游戏、修改世界组合或传播到其他实例。Hub 配置重置仍只处理 Hub 偏好，不重置游戏选项。

## 历史发布

游戏来源新增按完整 tag 主动查询；只允许内置官方仓库，通过 GitHub releases/tags API 获取单个发布，tag 作为独立 URL 路径段编码。普通 Git 标签不一定有发行记录；例如 DDA 0.H 发行标签为 `0.H-RELEASE`。

查询结果合并到当前来源列表，同 tag 替换，不下载；单来源列表最多 200 项，总目录写入不得超过已有读取上限 16 MiB；超限拒绝替换可读缓存。失败保留缓存。手动“更新版本”仍重建近期 30 项及最新正式版列表，历史查询可以再次执行；不会后台遍历全部历史。下载仍沿用附件身份、大小和摘要缓存复用。

## 解压到登记

已解压记录新增打开目录与导入/登记入口，后端按记录 ID 查找目录，不接受任意前端起始路径；目录需存在且规范路径保持一致。原生选择器从该目录打开，用户继续明确选择实际游戏程序/.app 或单个资源包。选择取消不登记；游戏还需填写名称并确认导入；资源选择后按对应资源来源类型登记。

多入口和合集不猜选根目录。解压、打开、登记均不表示资源已部署/启用或游戏已经运行。删除原始下载包后，已有独立解压记录仍可使用；目录被搬走/替换时明确失败。

重新读取报告或切换目标/基线时，界面丢弃旧草稿和确认区域，旧预览的迟到响应不能出现在新目标上。已提交任务仍在后端继续记录，不因界面重建而取消。
